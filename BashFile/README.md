# Bash File Creator 🪄

The script that creates a new empty bash file with hashbang e makes it executable.

## How it works ⚙️

The scripts requires to user the following parameters:

- name of file(s)

The script accepts multiple file name as arguments and creates a new file(s) ready to be edit and writes in the hashbang e makes it executable only by the owner.

## How to use it 🚀

1. Make it executable   `chmod +x bashfile.sh` 
2. Execute the script   `./bashfile.sh arg1 arg2...`

## Why this script? 💡
Because it can makes this operation faster then create a (or multiple) new bash file(s).
